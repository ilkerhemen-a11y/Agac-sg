# AgaçİSG

Android-first occupational health and safety (İSG) question-and-answer app built with Expo and React Native.

## Development

- Install dependencies: `npm install`
- Start app: `npx expo start`
- Android APK build is configured through GitHub Actions.

The initial version focuses on the home screen and question-category UI. Real questions and answers will be supplied by the project owner and added later.
